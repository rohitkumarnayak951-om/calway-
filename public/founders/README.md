# Founder Images

Drop the real founder photos into this directory with the following filenames:

1. `rohit-kumar-nayak.jpg` (Rohit Kumar Nayak)
2. `abhimanyu-singh.jpg` (Abhimanyu Singh)

Recommended specifications:
- Format: JPG / JPEG / WebP / PNG
- Aspect Ratio: 1:1 square or portrait (will be cropped to circle with `object-fit: cover, object-position: center`)
- Resolution: Minimum 320x320px (400x400px+ recommended for crisp display on retina screens)
